ประวัติโรงเรียนโดยสังเขป

โรงเรียนเทศบาลบ้านส่องนางใย เป็นสถานศึกษาที่มีบทบาทสำคัญในการจัดการศึกษาให้กับชุมชนท้องถิ่นอย่างต่อเนื่อง มุ่งส่งเสริมการพัฒนาผู้เรียนควบคู่กับการอนุรักษ์สิ่งแวดล้อม และพัฒนาแหล่งเรียนรู้ทางธรรมชาติภายในโรงเรียน โครงการฐานข้อมูลพรรณไม้นี้จัดทำขึ้นเพื่อให้เยาวชนและผู้สนใจได้ศึกษาคุณค่าของทรัพยากรพืชพรรณผ่านระบบดิจิทัลที่ทันสมัย

โครงการงานสวนพฤกษศาสตร์โรงเรียน และการเรียนรู้ดิจิทัล

การใช้งาน QR Code และ NFC

สแกน QR Code

สแกนป้ายชื่อต้นไม้เพื่อเปิดดูรายละเอียด สรรพคุณ และข้อมูลทางพฤกษศาสตร์ได้ทันที

แตะ NFC Tag

นำสมาร์ตโฟนแตะที่จุดแท็ก NFC บริเวณต้นไม้เพื่อเข้าสู่ฐานข้อมูลโดยตรง
